"div" vs "section" vs "article"

Div

El elemento "div" se utiliza para agrupar elementos en un contenedor genérico y no tiene su propio significado semántico en HTML.

Se utiliza para dividir el contenido en secciones y para aplicar estilos a través de CSS.

Referencia

Section

El elemento "section" se utiliza para agrupar elementos en una sección genérica e independiente de un documento.

Referencia

Article

El elemento "article" se utiliza para representar un contenido independiente y autónomo que puede ser reutilizado y distribuido por separado del resto del contenido.

Block and Inline elements

Block elements

Los elementos de bloque siempre comienzan en una nueva línea y ocupan todo el ancho disponible.

Algunos ejemplos de elementos de bloque son: "div", "h1", "p", "ul", "ol", "li", "table", "form".

Inline elements

Los elementos en línea no comienzan en una nueva línea y solo ocupan el ancho de su contenido.

Algunos ejemplos de elementos en línea son: "span", "a", "img", "strong", "em", "input", "label".
