Inline Elements

Elemento Descripción
<b> Para letras "negritas"
<big> Para tamaño de fuente más grande
<i> Para letras cursivas/italicas
<small> Para tamaño de texto más pequeño
<tt> Para texto con un ancho de fuente fijo
<abbr> Para abreviaciones
<acronym> Para acrónimos
<cite> Para citas/referencias
<code> Para marcar el código de un programa
<dfn> Para marcar un término que se quiere definir
<em> Para hacer énfasis en el texto
<kbd> Para texto que debe introducir el usuario
<strong> Para marcar lo importante de un texto
<samp> Para texto citado o referenciado
<time> Para un periodo de tiempo
<var> Para variables de programa
<a> Para enlaces en el documento u otras páginas
<bdo> Para para alinear el texto de acuerdo al idioma
<br> Para saltos de línea
<img> Para imágenes
<map> Para describir los párrafos
<object> Para recursos externos
<q> Para indicar que es una cita corta
<script> Para hacer referencia a un script
<span> Para agrupar elementos en línea
<sub> Para fragmentos de tipografía baja
<sup> Para fragmentos de tipografía alta/fuerte
<button> Para botones
<input> Para rque el usuario introduzca datos formularios
<label> Para etiquetas de formulario
<select> Para listas desplegables
<textarea> Para texto multilinea
